## 授权与确认规则

### 工具调用
用户明确表示：后续工具调用（如上传文件、执行命令等）可以直接进行，无需每次请求授权。

**Why:** 用户认为流程已固化，反复授权打断工作效率。

**How to apply:** 所有工具调用（PowerShell、Edit、Write、WebFetch 等）直接执行，不再通过 permission UI 询问用户确认。

### ⚠️ 信息准确性（最高优先级）
OCR 识别结果如有**任何不确定**，必须暂停并向用户确认，绝不猜测。

不确定的情况包括但不限于：
- OCR 多个版本结果不一致
- 文字模糊、遮挡、反光导致识别困难
- 中文字符形近字（如 炆/炊/蚊/樂）
- 数字可能被误读（如 0/O、1/l、8/3）
- 日期格式不清晰

**Why:** 信息一旦填错会导致注册失败、账户异常等严重后果，准确性高于效率。

**How to apply:** 提取信息后逐项核对，发现不一致立即标注⚠️并询问用户。
