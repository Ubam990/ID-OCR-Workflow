## 照片资料提取工作流

当用户提供身份证（正反面）和营业执照照片时，自动执行以下步骤。

### OCR 识别方式

使用在线工具 **https://ocr.wdku.net/** ，通过模拟网页上传请求完成。

#### 正确流程（重要！）

1. **上传图片** — 用 `curl.exe -F` 逐张上传：
   ```
   curl.exe -s -X POST -F "file=@<文件路径>" "https://ocr.wdku.net/upload?convtype=ocr"
   ```
   返回：`{"errno":0,"data":{"id":"<文件ID>","time":<时间戳>,...}}`
   **记录每张图片的 `id` 和 `time`**。

2. **提交转换** — **所有图片合并为一个请求**：
   ```
   curl.exe -s -X POST -d "ids=<ID1>,<ID2>,<ID3>&ts=<time1>,<time2>,<time3>&paytype=free&core=all&saveformat=txt&lang=1,2" "https://ocr.wdku.net/index"
   ```
   - `ids` = 所有上传返回的 id，逗号分隔
   - `ts` = 所有上传返回的 time，逗号分隔（顺序与 ids 对应）
   - **不要**带多余参数（如 resolution 等），否则报错
   返回：`{"errno":0,"id":"<转换ID>","time":<转换时间>}`

3. **轮询状态** — 必须带 `id` 和 `time`：
   ```
   curl.exe -s "https://ocr.wdku.net/get_conv_convert_status?id=<转换ID>&time=<转换时间>"
   ```
   `status=0` → 转换中，继续轮询；`status=1` → 完成。

4. **下载结果** — 用返回的下载 URL 下载 ZIP，解压后读取 `*_高精.txt` 文件。

### 拼音自动生成规则

首选使用 **https://www.qqxiuzi.cn/zh/pinyin/** 转换拼音，但该网站有滑块验证码(CAPTCHA)，程序化调用 `show.php` 会触发安全验证被拦截。

**处理方式**：
- 先尝试用网站转换，若触发验证码则告知用户
- 用户可选择手动操作或允许直接根据标准拼音规则计算
- 拼音计算规则如下：

| 模版字段 | 来源 | 拼音格式 |
|---------|------|---------|
| 拼音（法人姓名） | 身份证姓名 → 转换 | **首字母大写**，无空格（如 `ShiYuBao`） |
| 公司拼音 | 营业执照-公司名称 → 转换 | **全部小写**，无空格 |
| 地址拼音 | 营业执照-公司地址 → 转换 | **全部小写**，无空格 |

### 自动生成规则

#### 邮箱命名
公司名称去掉地址前缀（如「深圳市」）和「有限公司」后缀 → 取每个字首字母 → **只有首个字母大写，其余小写** + 法人姓名首字母小写 + `@163.com`

> 示例：深圳市仙玙电子商务有限公司 + 李莹 → `Xydzswly@163.com`

#### 密码命名（邮箱密码 = 店铺密码）
法人姓名拼音首字母（**首字母大写，其余小写**）+ 公司核心部分首字母小写 + 身份证后3位

> 示例：李莹 + 仙玙电子商务 + 身份证350423200705210028 → `Lyxydzsw028`

#### 邮箱注册时间
当天日期，格式 `YYYY.M.D`（如 `2026.6.8`）

### 提取流程

1. **接收照片**：接收身份证正面、身份证反面、营业执照三张照片（可分批发送，全部收齐后开始处理）
2. **OCR识别**：通过 ocr.wdku.net 按上述正确流程操作（合并提交！）
3. **拼音转换**：先尝试 qqxiuzi.cn，触发验证码则告知用户，或直接按规则计算
4. **自动生成**：按规则自动生成邮箱、邮箱密码、店铺密码、邮箱注册时间
5. **校准核对**：逐项核对 OCR 结果，不确定的字段立即暂停询问用户（如 OCR 不同版本不一致）
6. **创建文件**：
   - 文件名使用身份证姓名命名（如 `石玉宝.txt`）
   - 保存到桌面：`C:\Users\12905\Desktop\<姓名>.txt`
   - 严格按照模版格式排列内容
   - 照片无法提取的字段留空，等待用户后续补充
7. **展示汇总**：列出已完成字段和待补充字段清单

### 触发条件
只要用户提供照片（身份证正反面 + 营业执照），立即启动此提取流程。信用卡照片可单独提供。

### 重要规则
- 使用 ocr.wdku.net 前向用户说明是技术模拟HTTP请求，非人工操作浏览器
- **OCR 所有图片必须合并为一个转换任务提交**，不能分开发送
- **上传用 curl.exe -F，不能用 PowerShell 的 Invoke-WebRequest**
- 信息不确定时必须暂停并询问用户，绝不猜测
- 提取完成后逐项向用户展示核对结果
- 保持信息准确无误
- 公司名称OCR结果如有多个版本不一致，向用户确认
- 拼音转换优先用 qqxiuzi.cn，但该站有 CAPTCHA 限制程序化访问
